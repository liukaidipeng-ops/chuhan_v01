# 楚汉·三维象棋

水墨风三维中国象棋：可与朋友联机，也可与电脑对弈。

**在线游玩：** https://liukaidipeng-ops.github.io/chuhan_v01/

- **人机对战**：新兵 / 校尉 / 霸王三档；霸王每步深算约五秒，极难战胜。电脑吃子会嘲讽，你久不落子它会出言相激。
- **联机**：创建房间 → 把邀请链接或二维码发给朋友，对方点开即入局；手机、电脑、微信内均可。掉线会自动重连并续上原局（切后台、换网络后立即探活重连；心跳里核对双方步数，丢了消息自动补发），任何一方掉线时双方时钟暂停。
- **回到对局**：没下完的局会记在本机，关掉页面后大厅里出现「回到对局」——人机、本地对战原样恢复（含揭棋的随机布局、兵法的军功与等级），联机重新入座（房主连中继丢了快照也能用本机存的棋局恢复房间）。
- **复盘**：终局后点「复盘」，从第一步起逐步前进、后退或自动播放整盘棋，各模式通用。
- **动画速度**：设置里可选 1× / 1.5× / 2× / 3×，默认 1.5×。
- **揭棋**：创建房间或本地对战时选「揭棋」。将帅明摆，其余十五子反扣（汉朱漆、楚黑漆，背面极淡地印着所在位置的字）随机摆放；暗子按位置走，一动即翻开现出真身，翻开的士象可以过河；被吃的暗子只有吃子方知道。联机时双方各持一半密钥洗牌（承诺哈希可核验），谁也看不到对方的牌。四十回合无吃子判和，同一子长将、长捉不得超过六回合。
- **兵法**：创建房间或本地对战时选「兵法」（不与揭棋混用，暂无人机）。保留象棋全部走法，加入军功、升级与生命值：吃子、将军、兵卒过河得军功，被吃也有补偿，第十六回合起每回合自动加功。每回合可花军功给一枚子升一级：二级只长血（2 血），三级 3 血并解锁兵种技能；车、兵卒、士可升四级——车 4 血（20 功），兵卒（8 功）、士（4 功）四级不加血、各得新技能；士、相/象升级便宜，二级起的士攻击力为 2，可以一刀砍死 2 血的子。每击杀一个敌方单位，那枚子腰带上镶一片甲，下次升级少花 1 功（升级时用掉）；悬停或长按棋子可看它的击杀数。棋身材质表示等级：一级木、二级乌银错花（银身嵌乌银回纹）、三级錾金（鱼子地上起凸云雷纹）、四级羊脂白玉金缕（暖白玉身、金丝卷草、金口沿），升级后字面换成掐丝珐琅（汉朱红、楚乌黑，银丝/金丝勾边），金属与玉在 HDR 影棚环境光下有真实反光；头顶细血条汉红楚绿；兵法模式里兵种出场人数随等级增加，车四级是双锤大将骑马领三辆战车，兵卒四级是持大盾、斩马刀的金甲兵，士四级是三名金甲金盾的禁卫。走到敌子格时，敌子血量不超过攻击力就吃掉，否则掉血、进攻方退回原位。兵种技能：兵拒马（不占行动，架完再走一步）、车冲阵（以直线上第一枚子为跳板，跳板挨 1 点伤害，落到它身后一格；身后有子一击可杀就吃掉占位，打不死就扣血退回）、马踏营（只能在敌方半场用）、炮霹雳（一开炮就齐射覆盖五格，留焦土）、相齐射、楚战象践踏（被动）、士护驾；四级技能都是被动：兵卒「神速营」（八方向直线 1～2 格，可越子、不能攻击）、兵卒「回防」（后退一格）、士「铁甲禁卫」（九宫内上下左右走一格）。每升一级换一个称号（汉军兵 → 汉伍长 → 汉什长 → 无当飞军；楚军卒 → 楚锐卒 → 楚持戟 → 江东甲士……）。被动技能不用按按钮，作为普通走法出现，同一回合可与主动技能一起用。汉主帅兵法「召回良将」复活一子，楚主帅兵法「破釜沉舟」连走两步，各限一局一次；二十军功可发终极兵法：汉「四面楚歌」使楚军两回合兵心涣散（只有将能照常走，其余的子不能移动、不能用技能，只能吃掉正在将军的那枚子；楚军这期间不算将军，没被将军时可以停着）、楚「鸿门宴」让汉帅三回合不能动（汉士「护驾」可闯帐破解）。两种终极兵法发动后，被影响一方的屏幕四周会变模糊，被困的子脚下缠着锁链。本回合还有技能可用时，屏幕下方会闪烁提示。电脑上鼠标悬停、手机上长按按钮、兵法签或棋子可看详细说明。所有数值集中在 `source/src/bingfa.js` 的 `CFG` 里调整；本地兵法局右侧「調」按钮（或网址加 `#bfdebug`）打开调试面板，可摆子、改等级血量甲片军功、清冷却、跳回合。
- **观战**：房间已有两位棋手时，再打开同一链接的人自动入席观战（最多 8 人）。观众以士兵形象站在楚河木桥上，可自取名号、随时站队汉/楚、发言拱火、哈哈大笑；不影响对局。
- **兵种演出**：兵卒步兵列阵、车为驷马战车、马为重甲骑兵、炮为铜炮齐射、相为汉军弩手、象为楚军战象、士为刀盾近卫、帅将主帅亲征；步兵与炮乘船渡河，车马涉水。吃子时双方兵种当场对抗。
- **兵种台词**：每个兵种移动、击杀各有台词，汉楚两军声线不同；击杀时多人齐喊。
- **营地士气**：吃子时全营擂鼓欢呼，被吃方摇头丧气；连吃三子且不丢子，胜方几名护卫过桥冲到对方营前叫阵，被吃方每次有三四人丢盔弃甲逃走（一局最多逃掉三分之二，新开一局恢复）。
- **画面档位**：完整电影镜头 / 精简特效 / 低特效；血腥程度 高 / 中 / 低 / 关（高档有喷溅血雾、随机形状的血迹与飞溅血点）。血迹、焦土、裂痕会一直留在棋盘上，同一处反复厮杀越叠越黑。
- **棋子款式与模型**：常规、揭棋开局可选棋子款式（木 / 银 / 金 / 玉，联机双方一致）；设置里「棋子显示」可改成用兵种模型代替棋子（兵法模式下模型随等级换装）。
- **操作**：拖动旋转、滚轮或双指捏合缩放；按住鼠标中键拖动（手机双指一起拖）平移画面，「視」按钮闪烁时点一下归位。右侧按钮为 言 / 悔 / 譜 / 視 / 停 / 設，认输、退出、画面档位都在「設」里。
- **暂停**：人机、本地随时可停；联机每人每局 3 次、每次最多 2 分钟，双方时钟一起停，到点自动继续。
- **计时**：名牌上显示总时间与本步剩余时间；最后 10 秒屏幕中央出倒数大字、四周泛红，本方观战兵坐立不安。
- **绝杀**：满屏朱砂手书「绝杀」；下出马后炮、卧槽马、重炮、铁门栓等有名的杀法时直接写杀法名。
- **第五版补充**：兵法里甲片攒够会自动升级（不花军功），升到四级的子得到一位楚汉名将的名字；相 / 象可升四级，三级新技能「飞越」（无视塞象眼），齐射、践踏挪到四级；打不死的目标标「-1」，能一击杀死才标「殺」；右侧「法」按钮是规则速览，调试入口在设置里。汉相的模型是谋士车驾，士披重甲持长刀巨盾。模型模式下每队领头的背一面写着棋子字的旗，脚下有汉红楚黑的光圈。退出对局直接回主菜单。
- **更新说明**：大厅底部「更新」或设置最下方可以查看。
- **终局**：将死时胜方全军冲上棋盘包围敌帅，败方丢盔弃甲四散；随后进入历史结算（垓下·乌江 / 彭城之败）。
- `index.html` 是完整游戏（单文件，约 3.4MB，内含配音与音效），放到任何静态网站都能用。

## 目录
- `index.html` — 打包好的游戏
- `source/` — 源码与构建脚本
  - `npm install && node build.js` 生成 `dist/site/index.html`
  - `node test/rules.test.js` 规则引擎测试；`node test/jieqi.test.js` 揭棋规则测试；`node test/bingfa.test.js` 兵法规则测试；`node test/engine.test.js` 人机引擎测试
  - `voice/lines.json` 台词表，`voice/gen.py` 配音生成脚本（需 Kokoro 模型）
  - `sfx/manifest.json` 真实录音素材清单（均为 CC0 公有领域；人群呐喊为本项目用 Kokoro 多声线合成）
  - `voice/gen_units.py` 兵种台词与人群呐喊生成脚本
  - `fonts/` 开局题字用的行楷字体子集（志莽行书，SIL OFL 1.1）
  - `tools/nettest2.py`、`tools/spectest.py`、`tools/jqnet.py` 联机、观战、揭棋联机全流程测试；`tools/jqlocal.py` 揭棋同屏随机对局测试；`tools/bfnet.py`、`tools/bflocal.py` 兵法联机与同屏随机对局测试；`tools/reconnect.py` 断线重连、丢消息补发与「回到对局」测试
