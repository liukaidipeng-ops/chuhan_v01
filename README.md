# 楚汉·三维象棋

水墨风三维中国象棋：可与朋友联机，也可与电脑对弈。

**在线游玩：** https://liukaidipeng-ops.github.io/chuhan_v01/

- **人机对战**：新兵 / 校尉 / 霸王三档；霸王每步深算约五秒，极难战胜。电脑吃子会嘲讽，你久不落子它会出言相激。
- **联机**：创建房间 → 把邀请链接或二维码发给朋友，对方点开即入局；手机、电脑、微信内均可。
- **揭棋**：创建房间或本地对战时选「揭棋」。将帅明摆，其余十五子反扣（汉朱漆、楚黑漆，背面极淡地印着所在位置的字）随机摆放；暗子按位置走，一动即翻开现出真身，翻开的士象可以过河；被吃的暗子只有吃子方知道。联机时双方各持一半密钥洗牌（承诺哈希可核验），谁也看不到对方的牌。四十回合无吃子判和，同一子长将、长捉不得超过六回合。
- **兵法**：创建房间或本地对战时选「兵法」（不与揭棋混用，暂无人机）。保留象棋全部走法，加入军功、升级与生命值：吃子、将军、兵卒过河得军功，被吃也有补偿，第十六回合起每回合自动加功。每回合可花军功给一枚子升一级：二级只长血（2 血），三级 3 血并解锁兵种技能，车可升四级（4 血、20 功）；士、相/象升级便宜，二级起的士攻击力为 2，可以一刀砍死 2 血的子。每击杀一个单位，那枚子腰带上镶一片甲，下次升级少花 1 功（升级时用掉）。头顶细红格是血量，金星是等级；兵法模式里兵种出场人数随等级增加。走到敌子格时，敌子血量不超过攻击力就吃掉，否则掉血、进攻方退回原位。兵种技能：兵拒马（不占行动，架完再走一步）、车冲阵、马踏营、炮霹雳（五格落弹留焦土）、相齐射、楚战象践踏（被动）、士护驾。汉主帅兵法「萧何追韩信」复活一子，楚主帅兵法「破釜沉舟」连走两步，各限一局一次；二十军功可发终极兵法：汉「四面楚歌」使楚军两回合兵心涣散（除将外只能吃子、不能用技能）、楚「鸿门宴」让汉帅两回合不能动。电脑上鼠标悬停、手机上长按按钮、兵法签或棋子可看详细说明。所有数值集中在 `source/src/bingfa.js` 的 `CFG` 里调整；本地兵法局右侧「調」按钮（或网址加 `#bfdebug`）打开调试面板，可摆子、改等级血量甲片军功、清冷却、跳回合。
- **观战**：房间已有两位棋手时，再打开同一链接的人自动入席观战（最多 8 人）。观众以士兵形象站在楚河木桥上，可自取名号、随时站队汉/楚、发言拱火、哈哈大笑；不影响对局。
- **兵种演出**：兵卒步兵列阵、车为驷马战车、马为重甲骑兵、炮为铜炮齐射、相为汉军弩手、象为楚军战象、士为刀盾近卫、帅将主帅亲征；步兵与炮乘船渡河，车马涉水。吃子时双方兵种当场对抗。
- **兵种台词**：每个兵种移动、击杀各有台词，汉楚两军声线不同；击杀时多人齐喊。
- **营地士气**：吃子时全营擂鼓欢呼，被吃方摇头丧气；连吃三子且不丢子，胜方几名护卫过桥冲到对方营前叫阵，被吃方每次有三四人丢盔弃甲逃走（一局最多逃掉三分之二，新开一局恢复）。
- **画面档位**：完整电影镜头 / 精简特效 / 低特效；血腥程度 高 / 中 / 低 / 关。
- **终局**：将死时胜方全军冲上棋盘包围敌帅，败方丢盔弃甲四散；随后进入历史结算（垓下·乌江 / 彭城之败）。
- `index.html` 是完整游戏（单文件，约 3.4MB，内含配音与音效），放到任何静态网站都能用。

## 目录
- `index.html` — 打包好的游戏
- `source/` — 源码与构建脚本
  - `npm install && node build.js` 生成 `dist/site/index.html`
  - `node test/rules.test.js` 规则引擎测试；`node test/jieqi.test.js` 揭棋规则测试；`node test/bingfa.test.js` 兵法规则测试；`node test/engine.test.js` 人机引擎测试
  - `voice/lines.json` 台词表，`voice/gen.py` 配音生成脚本（需 Kokoro 模型）
  - `sfx/manifest.json` 真实录音素材清单（均为 CC0 公有领域；人群呐喊为本项目用 Kokoro 多声线合成）
  - `voice/gen_units.py` 兵种台词与人群呐喊生成脚本
  - `fonts/` 开局题字用的行楷字体子集（志莽行书，SIL OFL 1.1）
  - `tools/nettest2.py`、`tools/spectest.py`、`tools/jqnet.py` 联机、观战、揭棋联机全流程测试；`tools/jqlocal.py` 揭棋同屏随机对局测试；`tools/bfnet.py`、`tools/bflocal.py` 兵法联机与同屏随机对局测试
