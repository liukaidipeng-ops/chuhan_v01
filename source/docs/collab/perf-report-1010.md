# 优化部 性能现状报告（10-10，改代码之前的基准）

测法、局限见 `source/tools/perf/README.md`。线上版本 2026.10.10-0e1c2a，手机尺寸、画质中、技能模式人机。

| 场景 | 游戏每秒画几帧 | 每帧绘制次数 | 每帧三角形 | 主线程占用（CPU 降速 4 倍） |
|---|---|---|---|---|
| 大厅空闲 | 0（不画） | 0 | 0 | 18～22% |
| 对局静止·省电开（手机默认） | **28** | 约 340 | 22～29 万 | 32% |
| 对局静止·省电关 | **57**（高刷手机跟屏幕 90/120） | 约 340 | 22～29 万 | 44% |
| 走子 / 技能演出 | 满帧（代码：演出时取消省电限帧） | 250～400 | 约 20 万 | 长任务最长 0.28 秒（省电关一次 1.5 秒，待查） |
| 电脑思考 | 同静止 | 约 400 | 约 22 万 | 与静止持平（电脑在后台线程算，不卡画面） |
| 结算过场 | 满帧 | 约 240 | 约 23 万 | 长任务最长 0.25 秒 |

- 每帧 340 次绘制里：棋盘底座和装饰（金边、铜包角、木梯等，不会动）约 124 次；32 颗棋子各 3 次 = 96 次。
- 静止时每帧脚本最费的：两边军营小兵逐帧算姿势（约占采样 16%），旗子逐顶点摆动并重算法线（约 4%）。
- 首屏：`index.html` 2.84 MB（压缩后 1.13 MB；three.js 636 KB、两个字体 560 KB），页面一开还并行取 `sfx.bin` 1.46 MB。降速 4 倍时页面解析完约 5～7 秒。
- 内存：首局几何体 153→约 300、贴图 52→约 110，开新局场景清回去、堆 62→44 MB，暂未见明显泄漏，要长局复查。

## 补测：开兵种模型（设置里“模型”开）
- 每帧 **1579 次绘制、53 万三角形**、投影子的物体 979 个（默认模式 346 次 / 29 万 / 193 个）。
- 绘制次数是默认的 4.6 倍：四组兵种小队各约 100 次，每个模型拆成很多小网格。手机上最怕的就是绘制次数多。

## 模型预算（草案，10-10；真机核实后修订）
给角色部（局内）和以后的 CG 部（过场）照着做。数字是“手机中档画质下不掉帧”的保守估计，不是实测上限。

**局内（棋盘上同时在画）**
| 项 | 预算 |
|---|---|
| 整帧绘制次数 | ≤ 400（目标 250） |
| 整帧三角形 | ≤ 40 万 |
| 单个兵种 / 角色 | ≤ 5,000 三角形；同材质合并，蒙皮合成 1～3 个网格（≤ 8 次绘制） |
| 骨骼 | 每个蒙皮网格 ≤ 40 根 |
| 贴图 | ≤ 512×512，能共用就共用 |
| 两兵对打演出模块 | 同时上场加起来 ≤ 3 万三角形、≤ 30 次绘制；出场前先编好着色器，打完把几何体和贴图释放 |
| 影子 | 只给主要角色开投影 |

参考：虎骑一只 7,812 面、70 个网格——面数可以，网格数要合到 8 个以内。

**过场 CG（放过场时棋盘、军营不画）**
| 项 | 预算 |
|---|---|
| 整帧绘制次数 | ≤ 200 |
| 整帧三角形 | ≤ 60 万 |
| 主角 | 每个 ≤ 3 万三角形、≤ 6 个网格、骨骼 ≤ 60 根 |
| 贴图 | ≤ 1024；主角脸可一张 2048 |
| 包 | 单独一个文件，不进 `index.html`；每段压缩后 ≤ 3 MB；放之前才下载，有进度，下载失败能跳过 |
| 影子 | 只给主角开 |

## P1、P2 之后（10-10 12:45 复测）
- 每帧绘制：346 → 258（P1，已上线）。影子图另画 73 次，省电静止时每 0.5 秒才重画一次。
- 对局静止（省电，降速 4 倍）：每秒画 30 → 15 帧，主线程 37% → 24%（P2，交 TD）。
- P2 之后静止时 CPU 采样：军营小兵约 9%，旗子摆动约 3%，其余是浏览器自身。换到真手机约 2%，暂不值得再抠。

**下一批候选**（按收益排；都要真机数据确认）
1. 兵种模型模式每帧 1579 次绘制：角色部在合网格（虎骑 70 → ≤8），合完我来量。
2. 棋子每颗 3 次绘制，32 颗共 96 次：可以用“实例化”合成几次。但棋子会升级换皮（木银金玉）、各有字面，要 TD 和美术总监一起定方案，还没动。
3. 全屏纸纹叠加层：真机用 `?perf` 和 `?perf&nopaper` 对比才知道值不值得改（`?perf` 面板的帧数要等 TD 改成数真画的帧才准）。
4. 首屏：`index.html` 压缩后 1.13 MB，页面一开同时下 1.46 MB 的音效包。音效包晚点下要声音部改 `audio.js`。
