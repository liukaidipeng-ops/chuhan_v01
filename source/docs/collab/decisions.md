## 2026-10-04

- **防守子太弱、冲阵用得离谱：士反击近战、象反击远程**（用户原话：“冲阵作为成本最高的技能，它的使用率有点高的离谱；而士和象作为升级成本最低的防御棋子，几乎没人升级……考虑让士初始状态下自带被动：反击，当被近战击中后，会先受一点伤害，随后反击敌人（和拒马不一样的顺序相反），对远程（炮和相的齐射）无效，符合士持大盾的设定。相/象则是受到远程伤害以后，会反击敌人，对近战无效。”“我的策略是，肯定需要尽可能偏进攻，不然整局下起来很沉闷，我不希望节奏过慢，不希望攻击过于强大，希望更多选择。”）
  - 细节（用户回答）：
    - 被打死时还反击吗：“1和2你都试一下，我倾向于2”——死了也还手 / 活下来才还手两种都测，倾向活下来才还手；
    - 还手伤害：“先选择2，也许可以考虑1”——先测固定 1 点，备选按自己的攻击力；设计初衷是“优先用远程解决士，这也许会让玩家保护好他们的炮”；
    - 远程：炮、霹雳、齐射；
    - 溅射不触发，但“冲阵算近战，当跳板士会反击”；
    - 用户解释“升级占回合”：每回合只能升一次，升了防守子就占了进攻子的升级。
  - **回春**（用户：“是否考虑给满级象相一个回血技能，待在象相周围一格范围内，回复一点生命值，每只象每局只能用一次”）：模拟里按主动技能做，满级相 / 象，周围一格己方子各回 1 血，每只象每局一次。

  - 正在测：车 15/15/20；车 15/15/20 + 其他子每档便宜 1～2 点（Code 暂定的数）；车 10/12/20 作对照；将帅攻击 2 提前。没定。
- **新测试方向：主公技（破釜、召回）15 回合后才能用**（用户原话：“改成15回合后才能使用主公技（破釜和复活）”；确认“打满 15 回合、第 16 回合起”——用户：“你的理解是对的”）
  - 模拟预设 `arts-from16`（不叠加方案 A）。还没定。
- **电脑策略：军功收益最大化**（用户原话：“军功是重要资源，如何集合局势，让军功收益最大化，是人机需要重点考虑的问题，而不是一味升级高级棋子，比如车。前期升级兵的收益是否大于车？需要考虑。”）
  - Code 用对照实验回答：同一电脑只改前 15 回合的升级策略（先升兵 / 不急着升车 / 攒军功只保命），和原版换边对打。
- **电脑策略：军功当储备、极限升级、封锁期等级压制**（用户原话：“执楚三回合无法用技能和升级，意味着执楚的棋子三回合无法通过升级回血和加通过升级增加生命值防止被秒，这个是一个绝佳的反击窗口期，意味着楚方棋子都变得脆弱。counter 破釜的一种方法，可能是提前攒军功？这样也许可以利用等级压制，来吃初级棋子。”“目前的人机会不会利用极限升级，来最大化升级的收益？比如把血量降到最后一格，再升级。因为每次升级都会满血”）
  - 注意：“楚方三回合不能升级”是方案 A（模拟中），现行规则只封主动技能。
  - 回答用户：现在的电脑没有极限升级的策略（估值主要看当前血量，只要升级合算就当回合升，满血也升）；也不会有意攒军功当储备。
- **设计初衷：汉方面对破釜要算账，不能本末倒置**（用户原话：“执汉必须考虑收益：防守破釜的收益，是否大于利用破釜的debuff打反击的收益？如果小于，那么完全可以考虑放弃防守破釜，甚至可以制造陷阱，让对方使用破釜，提前运营防守反击。如果执汉只是为了防守破釜，而变得“不会下棋”，那就是本末倒置，毕竟被破釜不代表会输，防不住破釜也不代表直接失败，重要的还是己方如何运营。这是我设计这个游戏的初衷。”）
  - 对电脑的要求：汉方在“防破釜”和“放它破釜、封锁期反击”之间按收益选；可以故意引对方破釜。
  - 数据旁证：楚方用了破釜的局里汉方仍然赢 31.8%（现行规则）/ 37.3%（方案 A）。
- **电脑策略：汉方怎么对付破釜沉舟**（用户原话：“不能为了躲破釜而躲，执汉需要利用好破釜的debuff进行反击，尽可能拿回优势。”）
