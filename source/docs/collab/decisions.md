# 用户拍板的事（Claude Code 照用户原话记录，最新的在最上面）

## 2026-10-03

- **电脑策略：军功当储备、极限升级、封锁期等级压制**（用户原话：“执楚三回合无法用技能和升级，意味着执楚的棋子三回合无法通过升级回血和加通过升级增加生命值防止被秒，这个是一个绝佳的反击窗口期，意味着楚方棋子都变得脆弱。counter 破釜的一种方法，可能是提前攒军功？这样也许可以利用等级压制，来吃初级棋子。”“目前的人机会不会利用极限升级，来最大化升级的收益？比如把血量降到最后一格，再升级。因为每次升级都会满血”）
  - 注意：“楚方三回合不能升级”是方案 A（模拟中），现行规则只封主动技能。
  - 回答用户：现在的电脑没有极限升级的策略（估值主要看当前血量，只要升级合算就当回合升，满血也升）；也不会有意攒军功当储备。
- **设计初衷：汉方面对破釜要算账，不能本末倒置**（用户原话：“执汉必须考虑收益：防守破釜的收益，是否大于利用破釜的debuff打反击的收益？如果小于，那么完全可以考虑放弃防守破釜，甚至可以制造陷阱，让对方使用破釜，提前运营防守反击。如果执汉只是为了防守破釜，而变得“不会下棋”，那就是本末倒置，毕竟被破釜不代表会输，防不住破釜也不代表直接失败，重要的还是己方如何运营。这是我设计这个游戏的初衷。”）
  - 对电脑的要求：汉方在“防破釜”和“放它破釜、封锁期反击”之间按收益选；可以故意引对方破釜。
  - 数据旁证：楚方用了破釜的局里汉方仍然赢 31.8%（现行规则）/ 37.3%（方案 A）。
- **电脑策略：汉方怎么对付破釜沉舟**（用户原话：“不能为了躲破釜而躲，执汉需要利用好破釜的debuff进行反击，尽可能拿回优势。”）
  - 这是对电脑的要求，不是规则。汉方不该一味躲；楚方破釜之后的封锁期是汉方反击、追回优势的窗口。
  - 怎么量：`tools/bfsim.js` 新增“破釜前后”一行（破釜那一手汉方丢多少、封锁期里追回多少）；考卷新增“破釜反击”一类（在出题、核查）。
- **模型**：用户提醒“如果你俩想不出解法，我就换 fable”。
- **召回良将不占行动**（用户原话：“感觉可以试试：召回不占行动：召回之后，这回合还能再走一步（召回的棋子不能移动）”）
  - 用户想试，**没定**。模拟里：召回后这一回合还要再走一步棋（只能走子，不能再放技能、终极兵法、拒马），召回的那枚子这一步不能动。
  - 正在模拟：单独试、和破釜方案 A 一起试。
  - **召回后能不能当回合马上给召回的子升级**：用户定了——“能，但是不能移动，这样做可以防止召回的棋子直接被秒”。
    即：召回 → （可选）给召回的子升一级（照常扣军功、每回合最多升一次）→ 走另一枚子；召回的子这一回合不能动，升了级也不能动。
- **破釜沉舟之后的封锁期**（用户原话：“破釜后 3 回合‘不能使用技能’：被动技能也无法使用”“破釜期间，自动升级也不可用，破釜 debuff 完了以后自动升级”）
  - 破釜沉舟那一回合和之后 3 个楚方回合：主动、被动技能都不能用（践踏、神速营、回防、铁甲禁卫也封）；不能升级，甲片攒够也不自动晋升（甲片照攒）。
  - 封锁一结束，甲片攒够的子立刻自动晋升。
  - 鸿门宴（终极兵法）用户没提，暂时不封，待确认。
  - 这是用户提的削弱方案 A 的一部分。A / B 及其他方案正在模拟，**还没定要不要改进游戏**。
