## 1. 六问，一句话回答

**1. 考卷满分后还有没有区分度？缺哪类局面？**
基本没有。考卷是“认得机制”的回归题，不是“谁更强”的尺子：四个版本 6 万节点考 111 / 108 / 101 / 101，但排序和对打相反（9ff 108 分却对打输；cf47f5e 满分却 −105 Elo）；b18c278 只给 3 千节点也 35/37；5 道题乱走也九成判对。缺的是：真实自对弈/平淡局面（0 道）、楚方“何时该破釜”的时机题、四面楚歌（0）、甲片/自动晋升（0）、安静好棋与多步计划、少子残局。防守不是空白，但全是一步战术防守。【报告，核查员逐条复核 A5/A6 成立】

**2. 有没有电脑没见过的保留题？没有怎么建？**
考卷里没有：题全在仓库，chat 看得到、跑过、全对。但“电脑没见过的局面”另有两样已经在用：对打每局都是新局面、漏着率是新开的自对弈。要建保留题，方案是“种子 = 电脑文件哈希（定稿后才出题）+ 固定中立裁判 + 按损失计分 + 跑完公开”。核查员指出：A 路原型 2 的“已分出版本”**不算证据**（裁判就是 b18c278 自己；36 个局面差距 t≈1.45 不显著；9ff 和 25eb911 分不开）。所以这是“建议改”，不急。【报告 + 核查 A2/A15/A16】

**3. 执汉 44% 对执楚 77%，差距从哪来，总胜率怎么读？**
差距基本是游戏本身楚方占优（等强电脑汉只 36%，相当于楚 +100 Elo；这场估出的颜色项 +126±38，一致）。公平的强弱数是换边后的 60.7% / Elo +76；但它是提前停的，点估计偏乐观约 15～20 Elo，真值最可能 +55～+60，名义 95% 区间实际只有约 88～92% 的把握。分边看：执楚高出基准明显（约 2.3σ），执汉高出 8 个百分点但单看不显著（约 1.2σ）。**不能说“进步偏向楚方”，也不能说“两边都明显进步”。**【报告 B + 核查 B5/B6】

**4. 只对上一版、固定种子，够不够证明“更强”？阈值和局数上限合不合理？**
够证明“不比旧版明显弱”，**不够证明“更强”**——这是检验本来的设计（真弱 30 Elo 的版本只有 4% 能过；一样强的也有 52% 能过）。界 [-30,10]、α=β=0.05、600 局上限都合理，不用改。真要改的是三件事：① 文档和汇报把“通过”写成了“明显更强”（必须改措辞）；② 每轮都用种子 1（真实风险，但固定种子是为了可复现，改成“每个候选显式换一批新种子 + 打印种子”即可，不是必须改）；③ 只对上一版打，链式漂移的风险上线后才出现，加锚点对手当记录。【报告 B + 核查 B7/B8/B10】

**5. 换种子复跑结果一致吗？**
一致。种子 7001 固定 60 局：新版 39/60 = 65.0%，Elo +108（+20～+211）；执汉 16/30、执楚 23/30；按种子配对 11 对 2:0、17 对 1:1、2 对 0:2。B 路事先定的判法是“28～45/60 算一致、≥37 排除一样强”，两条都满足。LLR 2.49 没到界、显示“还没有结论”，这是正常的（60 局内出结论概率只有一半）。前 17 局和提前停那次逐局相同（17/17），说明按节点收手完全可复现。两批合计 104/167 = 62.3%（我算的，仅参考，H15 那批是提前停的有偏样本）。【我核实了结果文件；配对统计来自核查 C15】
