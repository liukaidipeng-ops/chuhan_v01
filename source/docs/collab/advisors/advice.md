### 要解决什么
- 几乎没人用（handoff 3.2，旧电脑 / 新电脑）：齐射 0.9% / 0.5% 的局；践踏打中每局 0.00～0.01 次；汉终极兵法 1.7% / 0.8%；决战 0%。

### 怎么改
1. **齐射、践踏**：照 Plan C 的定义，不加新改动。
   - 齐射：横竖 1～2 格，第一枚子挡住，扣 1 血，冷却 3。
   - 践踏：走到空格也踩，落点一圈敌子各扣 1 血，1 血的踩死，不加冷却。
   - 两个都提前到三级。
   - 已有的数据：旧电脑 600 局，汉胜 48.3%，不改是 49.9%；升到三级象的局 19% → 29%；齐射在 8% 的局里用过。Ham 当时定暂缓，是为了先解决“电脑会变通”。
2. **四面楚歌**：不改（Ham 10-05 定：“终极兵法就是用来快速结束战局的”）。放宽到 2 个汉子测过，补不了汉；现在又偏汉，更不该加强汉。
3. **决战**：不改、不测。没人用它，但它也不碍事，测试额度留给别的。

### 预期效果（猜测，要数据验证）
- 齐射：用过的局 ≥ 10%。践踏：每局打中 ≥ 0.3 次。
- 相、象升到三级的局明显比现在多。
- 汉胜率变化在 ±3 个点以内。如果到时还偏汉，践踏小幅帮楚也可以接受，由 Ham 定。
- ♟ 国际象棋的猜测：两个技能主要用来防贴脸，贴脸将死的比例会下降。🀄 中国象棋的猜测：践踏只扣 1，踩不死 2 血的贴脸子，要靠士补刀，所以“被将死的一方丢几个士象”比“践踏杀了几个子”更能说明问题。两个都看。

### 怎么测（到位以后）
1. **先考电脑懂不懂**：考卷补几道 Plan C 的题，会用的、会防的都要有（象落地踩死两兵、竖着射、先升象再踩、不去吃象落点旁边的子）。10-05 测过一次，换了电脑要重考。
   Ham 原话：“需要确保电脑明白践踏和齐射的运行机制，象的范围可谓非常大了”。
2. **重调权重**：规则一改，估值权重要重调（handoff 第 0 节）。Plan C 规则下自对打收数据、拟合，再对打确认没有变弱。
3. **对照**：同一个电脑（到位那版，按 Plan C 重调过权重），现行规则对 Plan C，每组 600 局，同一批开局逐局比。
4. **报的数**：汉胜率、平均回合；齐射 / 践踏使用率和击杀数；相、象升到三、四级的局占比；贴脸将死比例；被将死一方丢几个士象。
5. **极端诊断（可选）**：使用率还是很低时，把齐射、践踏的伤害临时调到 2，看电脑用不用，用来分清是技能弱还是电脑不懂（handoff 第 4 节）。

### 风险

## A2 · 2026-10-10 · 怎么把电脑练得更强（只是建议，请数值部先评估）

> **⚠️ 请数值部务必先看清楚再决定，不要照单执行。**（Ham 原话：“你们提建议，但是务必备注，让他也考虑清楚，不要盲目执行”）
> - 顾问部没有跑过你们的工具，对现在的电脑、拟合和 GitHub 排队的了解只来自 `ai-playbook.md`、`bfai-qualification.md` 和 NOTES。下面每条都可能已经做过、做不了，或者不值得做。
> - 请对每条回答：做过没有、值不值得、要多少工作量和额度、和现在的排期冲不冲突。不值得的直接说不做，并说明理由。
> - 要做哪几条、按什么顺序做，由 Ham 拍板，并按手册的流程走：一次只改一项，600 局对打，z ≥ 2 才算数。

### Ham 拍板（2026-10-10，拍板单 ai_a2 选 a，照数值部 N5 的推荐）
- 第 1 条：先做便宜版（拟合标签混入收数据时的搜索分），第 3 条做便宜版（帅、将身边九宫还空几格），两项放进下一轮调权重。
- 第 2 条：不做刺客，改成把 g4、g5、g6 里电脑输的关键局面收进考卷当闸门。
- 第 4 条：等电脑收敛以后，挑 2～3 个参数小范围扫描。
- “够强”标准加上：两版电脑用各个技能的比例差不多；考卷不退步。

### 要解决什么
- Ham 定的优先级：先训练出尽量完美理解机制的电脑，平衡数据才可信（N3）。线上电脑自对打汉胜 48%，新权重电脑 65%：电脑一变强，平衡的数字就变了。
- Ham 的目标原话：“AI 必须强到我悔棋也赢不了，至少很难赢”。
- 已经做了、不再重复提：自动调估值权重（Texel，对旧电脑 83%）、潜力估值、对方第二手升级（UP3K / r35）、会用升级的陪练（bfai_spar）、关键时刻多想（ai_time1）。

### 建议（四条，每条都附上“可能不值得”的理由）

**1. 深搜当“老师”（♟ 国际象棋提）**
- **怎么改**：调权重时，标签不光看“这局谁赢”，再用霸王档长时间深搜对同一个局面打的分。可以先试“胜负和深搜各占一半”。
- **为什么**：一局赢了，中间也可能有很多坏棋，拿胜负当标签很粗。国际象棋引擎普遍用深搜结果当标签。
- **预期**：同样多的数据，拟合出的权重更准；用新权重对 w_t4 下 600 局，得分 > 50% 而且 z ≥ 2。
- **代价**：深搜每个局面要花不少 GitHub 机器时间，基本不花额度。
- **可能不值得**：深搜用的就是现在的估值公式，老师和学生是同一个脑子，可能只是把原来的错再学一遍。数值部判断风险大，就只试一小批，或者不做。

**2. “刺客”陪练当闸门（🃏 桌游设计提）**
- **怎么改**：做几个只会一招狠招的陪练，招数都来自 Ham 真实对局里赢电脑的手法：
  - 第二手把兵升四级、神速营跳过来将军（g5）；
  - 升象吃炮（g4）；
  - 召回或背水以后马上升级突袭（g6）。
  新电脑要在“不退步”闸门之外，再对每个刺客各下若干局，不能明显输。
- **为什么**：自对打时两边是同一个脑子，有同一个盲区，所以不会有一方去惩罚它。g5 就是这样漏掉的。
- **预期**：每个刺客都能变成一个可以量化的缺口：现在的电脑对它的得分是多少，补了之后是多少。
- **代价**：每个刺客都是一个新变体，要写代码，花额度。可以先只做 g5 那一个。
- **可能不值得**：已经有的 bfai_spar（会用升级的陪练）可能已经覆盖大半。电脑对陪练变强，对线上电脑也可能变弱：r19 的候选 A 对陪练 55.2%、对线上 45.8%。所以刺客只能当附加检查，不能替代对线上的对打。

**3. 九宫安全特征：“砍不死的贴脸子”（🀄 中国象棋提）**
- **怎么改**：估值里加两项：
  - 有几枚敌子贴在帅、将身边一格，而且我方能打到它的子都砍不死它（它的血 > 我方能打到它的子的攻击）；
  - 帅、将还剩几个能躲的格子。
  加进 t4 下一轮要拟合的特征（计划里有“贴帅子数”），权重让拟合决定，不要人定。
- **为什么**：70～75% 的局是贴脸将死；只数贴脸的子有几个，分不清“砍得死”和“砍不死”，而这正是这个游戏杀法的关键。
- **预期**：拟合的检验误差下降；对 w_t4 下 600 局，得分 > 50%。
- **代价**：要算我方能打到的子，估值会变慢。手册说打分一慢就少算几层，反而可能变弱，所以一定要先量层数。
- **可能不值得**：现有的贴脸杀势、危险延伸可能已经间接覆盖了，加了也只是重复。

**4. 搜索参数交给机器调（SPSA，♟ 国际象棋提）**
- **怎么改**：把人手定的搜索参数（升级候选留几个、哪些情况多算一层、靠后着法少算几层等）交给 SPSA：每次随机把这些数往上或往下挪一点，两版对打，按胜负把数往好的方向移，反复几千局。
- **为什么**：手册说“算深最值钱”，这些参数决定能算多深、算哪些。
- **代价**：几千局在 GitHub 上要很久；要写一个反复调参的循环。
- **可能不值得**：GitHub 一次最多 256 段，还要给练电脑的其他测试留机器，可能会挤掉排期。参数太多时 SPSA 收敛很慢。

### 三位的分歧（先做哪条）
- ♟ 国际象棋：先做 1，标签准了，调出来的才对。
- 🃏 桌游设计：先做 2，专补 Ham 打出来的盲区。
- 🀄 中国象棋：先做 3，懂杀法才是真棋力。
- 共识：四条都应该一项一项对打验证；优先做主要花 GitHub 机器、少花额度的（1、4）；Ham 导出的笨棋是最值钱的数据。

### 建议补进“够强”的标准（供数值部和 Ham 考虑）
数值部现在的标准是：新一版对上一版赢不到约 55%，而且两版自对打的汉胜率差在 3 个百分点以内。另外建议考虑：
- 两版电脑用各个技能的比例差不多；
- 如果做了第 2 条，刺客陪练全部不明显输。

### 没列进来的
- 开局库：🀄 中国象棋提的，♟ 国际象棋反对。测平衡时前 10 步本来就是随机的，开局库帮不上平衡数据，只对和真人下有用，往后放。
- 小型神经网络当估值：手册已经列为第 2 步，要等第 1 步（调权重）的收益用完以后再说，这里不重复。

## A1 · 2026-10-10 · 偏汉：先拆原因，再按结果补

**Ham 已选这题先做**（“先解决偏汉问题吧，我同意。”）。

### 要解决什么
- 新电脑自对打 600 局，汉胜 **64.7%**（95% 区间 60.8–68.5）；线上电脑 3802 局是 48.2%（handoff 3.1）。
- 新电脑对旧电脑执汉、执楚都赢约 83%，所以不是电脑偏心，是**下得越好，规则越偏汉**。
- 已查到的事实：技能模式**汉先走**（`source/src/bingfa.js:114`，`turn: 'r'`）。
- 背景：召回“最多二级 / 当场可升 / 第一次升级半价”这几条，是第五～七轮在**旧电脑偏楚**时加上去补汉的（decisions.md 10-05）。电脑变强后，这些补丁可能补过头了。

### 三位的看法

**🃏 桌游设计**：先别急着补楚。现在汉身上叠着三层只有汉有的东西：先手、召回的几个补丁、四面楚歌。哪层是主因，改法完全不同。建议一批诊断一起跑，一次看清。

**♟ 国际象棋**：我还是押先手。下得越好，先手越值钱，这和 65% 只在强电脑上出现的现象对得上。另外，70% 的局是贴脸将死，节奏很快，先手多一步，可能就先升出一枚二级车。

**🀄 中国象棋**：传统象棋红先也略占优，但没大到 65%。我押召回：汉的召回能把二级车带回来、当场半价升级，楚的背水一战只是多走一步，补不回子力。两边的“翻盘”不对等。

### 第一步：诊断（只在模拟里改，不是改规则）

每组 600 局，用最强的新电脑，和基准**同一批开局逐局比**（前 10 步随机，同现在的设置）。几组可以一起排。

| 组 | 改什么（具体开关） | 想回答的问题 |
|---|---|---|
| D0 | 现行规则（基准，同一批开局重跑或复用 64.7% 那批） | 对照 |
| D1 | **楚先走**（其他全不变） | 先手值多少？需要数值部给模拟加一个“谁先走”的开关，不改游戏代码 |
| D2 | 召回去掉两条补丁：`r6.reviveUp: false`、`r6.reviveHalf: false`（保留最多二级、按兵种） | 召回补丁是不是补过头 |
| D3 | 两边主帅兵法都关（召回、背水都不能用） | 召回 / 背水这对不对称的翻盘机制，合起来偏谁 |
| D4 | 两边终极兵法都关（鸿门宴、四面楚歌） | 终极兵法偏谁（预计影响小，楚用 7.5%、汉 0.8%） |

不测：相 / 象四级技能。齐射、践踏几乎没人用（0.5% / 约 0），关了也看不出差别，等“死技能”那题再一起处理。

**怎么读结果**（汉胜率变化，D0 为 64.7% 时）：
- D1 楚先走后楚也赢到 60% 以上 → 主因是先手，走“补后手”路线（下面方案 1）。
- D2 降到 55% 以下 → 主因是召回补丁，走方案 2。
- D3 降很多、D2 不太动 → 是召回 / 背水这对机制本身不对等，走方案 3。
- 都只动几个点 → 原因是分散的，可能要组合，三位再议。
- 每组 600 局的误差大约 ±4 个点，差 5 个点以上才算真的有变化；逐局比会更准一些。

### 第二步：候选改法（等诊断结果出来，Ham 拍板后再测）

先列出来，诊断一出就能马上排，不用再等一轮讨论。

1. **补后手（先手是主因时）**：楚方开局军功 3 → 5，测 4 和 5 两档。
   - 理由：像围棋“贴目”，不动任何技能，最简单。第五轮测过“汉开局多 1 点”，说明开局军功是能调动平衡的。
2. **收召回（补丁是主因时）**：按 D2 的结果选一条：
   - 2a：去掉“第一次升级半价”（`reviveHalf: false`）；
   - 2b：去掉“召回当场可以升级”（`reviveUp: false`）。
   - 只砍一条，先测砍哪条更接近 50%。
3. **翻盘机制对等（召回 / 背水本身是主因时）**：楚背水一战的开启条件放宽，只给楚：车马炮最多剩 3 → 4 枚（而且比对方少）。
   - 需要数值部把 `beishui.maxLeft` 拆成汉、楚各一个值（现在两边共用）。
   - 这一条和“召回 / 背水开启条件”那题有关，那题以后会一起想。

### 预期效果
- 目标：新电脑自对打汉胜率回到 **50% ± 3**。
- 不能让别的指标变坏：平均回合不超过 50；六成以上对局 60 回合内下完（Ham 10-05 定的）；召回、背水的使用率不明显下降。

### 风险
- **D1 楚先走只是诊断**，不建议真改成楚先走：红先是象棋几百年的习惯，玩家会觉得别扭。
- 方案 1 只是加数，新手看得懂；但先手的价值可能随电脑变强继续涨，到时还要再调。
- 方案 2 是撤掉 Ham 自己加的补丁，撤之前要确认：旧电脑偏楚的问题会不会回来。所以方案 2 要**新旧两种电脑各跑一组**。
- 方案 3 要改引擎里一个共用开关，TD 有一点工作量。
- 规则改了，电脑权重要重调（handoff 第 0 节），所以候选改法尽量攒成一批再上。

### 三位的共识和分歧
