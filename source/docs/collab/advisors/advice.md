## A1 · 2026-10-10 · 偏汉：先拆原因，再按结果补

**Ham 已选这题先做**（“先解决偏汉问题吧，我同意。”）。

### 要解决什么
- 新电脑自对打 600 局，汉胜 **64.7%**（95% 区间 60.8–68.5）；线上电脑 3802 局是 48.2%（handoff 3.1）。
- 新电脑对旧电脑执汉、执楚都赢约 83%，所以不是电脑偏心，是**下得越好，规则越偏汉**。
- 已查到的事实：技能模式**汉先走**（`source/src/bingfa.js:114`，`turn: 'r'`）。
- 背景：召回“最多二级 / 当场可升 / 第一次升级半价”这几条，是第五～七轮在**旧电脑偏楚**时加上去补汉的（decisions.md 10-05）。电脑变强后，这些补丁可能补过头了。

### 三位的看法

**🃏 桌游设计**：先别急着补楚。现在汉身上叠着三层只有汉有的东西：先手、召回的几个补丁、四面楚歌。哪层是主因，改法完全不同。建议一批诊断一起跑，一次看清。

**♟ 国际象棋**：我还是押先手。下得越好，先手越值钱，这和 65% 只在强电脑上出现的现象对得上。另外，70% 的局是贴脸将死，节奏很快，先手多一步，可能就先升出一枚二级车。

**🀄 中国象棋**：传统象棋红先也略占优，但没大到 65%。我押召回：汉的召回能把二级车带回来、当场半价升级，楚的背水一战只是多走一步，补不回子力。两边的“翻盘”不对等。

### 第一步：诊断（只在模拟里改，不是改规则）

每组 600 局，用最强的新电脑，和基准**同一批开局逐局比**（前 10 步随机，同现在的设置）。几组可以一起排。

| 组 | 改什么（具体开关） | 想回答的问题 |
|---|---|---|
| D0 | 现行规则（基准，同一批开局重跑或复用 64.7% 那批） | 对照 |
| D1 | **楚先走**（其他全不变） | 先手值多少？需要数值部给模拟加一个“谁先走”的开关，不改游戏代码 |
| D2 | 召回去掉两条补丁：`r6.reviveUp: false`、`r6.reviveHalf: false`（保留最多二级、按兵种） | 召回补丁是不是补过头 |
| D3 | 两边主帅兵法都关（召回、背水都不能用） | 召回 / 背水这对不对称的翻盘机制，合起来偏谁 |
| D4 | 两边终极兵法都关（鸿门宴、四面楚歌） | 终极兵法偏谁（预计影响小，楚用 7.5%、汉 0.8%） |

不测：相 / 象四级技能。齐射、践踏几乎没人用（0.5% / 约 0），关了也看不出差别，等“死技能”那题再一起处理。

**怎么读结果**（汉胜率变化，D0 为 64.7% 时）：
- D1 楚先走后楚也赢到 60% 以上 → 主因是先手，走“补后手”路线（下面方案 1）。
- D2 降到 55% 以下 → 主因是召回补丁，走方案 2。
- D3 降很多、D2 不太动 → 是召回 / 背水这对机制本身不对等，走方案 3。
- 都只动几个点 → 原因是分散的，可能要组合，三位再议。
- 每组 600 局的误差大约 ±4 个点，差 5 个点以上才算真的有变化；逐局比会更准一些。

### 第二步：候选改法（等诊断结果出来，Ham 拍板后再测）

先列出来，诊断一出就能马上排，不用再等一轮讨论。

1. **补后手（先手是主因时）**：楚方开局军功 3 → 5，测 4 和 5 两档。
   - 理由：像围棋“贴目”，不动任何技能，最简单。第五轮测过“汉开局多 1 点”，说明开局军功是能调动平衡的。
2. **收召回（补丁是主因时）**：按 D2 的结果选一条：
   - 2a：去掉“第一次升级半价”（`reviveHalf: false`）；
   - 2b：去掉“召回当场可以升级”（`reviveUp: false`）。
   - 只砍一条，先测砍哪条更接近 50%。
3. **翻盘机制对等（召回 / 背水本身是主因时）**：楚背水一战的开启条件放宽，只给楚：车马炮最多剩 3 → 4 枚（而且比对方少）。
   - 需要数值部把 `beishui.maxLeft` 拆成汉、楚各一个值（现在两边共用）。
   - 这一条和“召回 / 背水开启条件”那题有关，那题以后会一起想。

### 预期效果
- 目标：新电脑自对打汉胜率回到 **50% ± 3**。
- 不能让别的指标变坏：平均回合不超过 50；六成以上对局 60 回合内下完（Ham 10-05 定的）；召回、背水的使用率不明显下降。

### 风险
- **D1 楚先走只是诊断**，不建议真改成楚先走：红先是象棋几百年的习惯，玩家会觉得别扭。
- 方案 1 只是加数，新手看得懂；但先手的价值可能随电脑变强继续涨，到时还要再调。
- 方案 2 是撤掉 Ham 自己加的补丁，撤之前要确认：旧电脑偏楚的问题会不会回来。所以方案 2 要**新旧两种电脑各跑一组**。
- 方案 3 要改引擎里一个共用开关，TD 有一点工作量。
- 规则改了，电脑权重要重调（handoff 第 0 节），所以候选改法尽量攒成一批再上。

### 三位的共识和分歧
- **共识**：先诊断，不先补；D1～D4 一起跑；目标 50% ± 3。
- **分歧**：主因是什么——国象押先手，中象押召回，桌游设计两者都不排除。等数据。
