# 顾问部交接包（数值部写，2026-10-10）

> 读者：顾问部（一个窗口，三位顾问：卡牌 / 桌游设计、国际象棋、中国象棋）。
> 你们的任务：根据数值部的测试数据，提技能和规则改法，规划游戏以后的设计方向。
> **规则、平衡、上不上线由 Ham（游戏设计者、老板）拍板**；数值部（Balance）负责测；TD（技术总监）负责写进游戏、上线。

## 0. 先说清楚：你们能做什么、不能做什么

- **能做**：从玩家体验、技能设计（反制、可读性、节奏、随机性、成长）、象棋棋理（杀法、攻防、开局 / 残局、人觉得什么好玩 / 憋屈）提方案；看 Ham 的对局复盘谈感受；替 Ham 想清楚取舍。
- **不能做**：
  - 不改游戏代码（`source/src/`）。
  - 不改数值部的工具（`source/tools/`）。
  - 不直接定规则。
- **你们是“角色”，底下是同一个模型**：论下棋，你们比不上游戏里的电脑。这是个新游戏，有血量、升级、技能，传统棋理和卡牌经验不一定对。
  比如：原来手定的估值公式，自动调参后发现差得很远——调出来的版本对原版赢 83%。**所以每个点子都要过模拟，数据说了算。**
- **规则改动攒成一批**：规则一改，电脑的估值权重要重调、平衡要重测（一轮大约半天到一天）。零碎改会拖慢“最强电脑”的进度。
- **省钱**：Ham 在意额度。三位顾问在同一个窗口里轮流发言、互相反驳，不要再开子代理。

## 2. 现行规则（游戏里“玩法说明”的原文摘要，技能模式）

**走法**
- 走法同中国象棋。
- 将死、困毙即负。
- 被将军时，只要先给某枚子升一级就能解将，就不算将死。
- 帅将没有血量、不能升级、不能被吃。

**军功**
- 开局 3，上限 30。
- 击杀加功：兵 +1，士相象 +2，马炮 +3，车 +5；被杀的子每升过一级再 +1。
- 其他加功：将军 +1；兵过河 +1；己方被杀一子 +1。
- 按回合进账：第 15 回合起每回合双方各 +1，第 45 回合起各 +2。

**升级**
- 每次行动前可以花军功升一级，不占行动。
- 价钱：
  - 车 10 / 12 / 20（四级 20）
  - 兵 3 / 5 / 8
  - 马、炮 5 / 7（最高三级）
  - 士、相 / 象 2 / 3（四级：士 4、相 / 象 5）
- 二级 2 血，三级 3 血并解锁兵种技能，四级不再加血、换新技能。
- 子自己杀敌记功，记满下一级的价钱就自动升级。

**攻击**
- 敌子血量 ≤ 攻击力就吃掉；否则只扣血，攻方退回原位。
- 攻击力：车马炮兵一二级 1、三级起 2；士、相 / 象二级起 2；帅将 1。

**兵种技能（三级解锁，有冷却）**

| 兵种 | 技能 | 效果 |
|---|---|---|
| 兵 | 拒马（二级就有） | 原地架矛两回合，不占行动；近身来犯的子先挨 1 点；冷却 4 |
| 车 | 冲阵 | 撞开直线上第一枚子（挨 1 点），落到它身后 |
| 马 | 踏营 | 无视蹩马腿，只在敌方半场 |
| 炮 | 霹雳 | 五格落弹、溅伤四周二级以上敌子 |
| 相 / 象 | 飞越 | 无视塞象眼 |
| 士 | 护驾 | 和帅将换位，可解将 |

**四级技能**

| 兵种 | 技能 | 效果 |
|---|---|---|
| 汉相 | 齐射 | 不动身，射斜线两格内一子，扣 1 |
| 楚象 | 践踏 | 被动：攻击或吃子后，落点一圈敌子各扣 1 |
| 兵 | 神速营 | 八方向疾行 1～2 格，可越子，冷却 5 |
| 兵 | 回防 | 后退一格，冷却 2 |
| 士 | 铁甲禁卫 | 九宫内上下左右一格，冷却 2 |

**主帅兵法（每局一次，只给落下风的一方：己方车马炮最多剩 3 枚、而且比对方少）**
- 汉「召回良将」：复活一种阵亡兵种里等级最高的那枚。死时一级回来还是一级，二级以上回来都是二级，血回满；放回这一兵种任意一个空开局位。当场可以花军功升一级，第一次升级半价；召回占这一回合。
- 楚「背水一战」：连走两步，最多吃一子。

**终极兵法（20 军功，每局一次）**
- 楚「鸿门宴」：汉帅三回合不能动（汉士护驾可以破解）。
- 汉「四面楚歌」：楚将 2 格内有 3 枚汉子时可发动；两回合内楚军只有将能走。

**决战**：双方车马兵炮都死光后，士象、帅将可以过河进攻，帅将 3 血；还有“夺营”胜法。

**定义好了、暂缓上线**（拍板单 r8，2026-10-05）：Plan C——相齐射改成横竖 1～2 格（冷却 3），象践踏走到空格也踩，两个都提前到三级。
- 测过 600 局（第七轮规则、旧电脑）：汉胜 48.3%，不改是 49.9%，平衡没变，对局稍长。
- 技能开始有人用了：楚象三级 19% → 29%，齐射 8% 的局用过。
- Ham 当时定：先解决“电脑会变通”，Plan C 暂缓。

## 3. 数据（2026-10-10，新规则）

### 3.1 平衡：电脑变强以后偏汉了（最要紧）

| 电脑 | 局数 | 汉方胜率 | 平均回合 |
|---|---|---|---|
| 线上电脑自对打（校尉，前 10 步随机） | 3802 | **48.2%**（95% 区间 47–50） | 49.9 |
| 新调权重的电脑自对打（同设置） | 600 | **64.7%**（95% 区间 60.8–68.5） | 44.4 |

- 新电脑对旧电脑执汉、执楚都赢约 83%，强得很对称；它自己跟自己下，汉方却明显占优。
- 也就是说，**下得越好，现行规则越偏汉**。人和高手的对局也可能这样。
- 原因还没拆。数值部能做的拆法：逐项关掉 / 改动不对称的规则（召回、背水、两边终极兵法、象 / 相四级技能），看汉胜率怎么动。

### 3.3 这个游戏实际怎么赢（旧电脑 3802 局）
- 将死 3794 局。其中将军的子有 2 血以上的占 91%；**贴在帅将身边将死的占 70%**（新电脑 75%）。车参与的将死 66%（新电脑 74%）。
- 也就是说，主要杀法是“**升了级、砍不死的子贴脸将军**”：一级士、帅攻击 1，砍不死 2 血的子。
- 被将死的一方开局 4 个士象，终局平均丢 1.7 个。
- 平均 44–50 回合；76%（新电脑 89%）在 60 回合内结束。

### 3.4 Ham 和霸王（最强档）的实战（复盘报告在 `source/tools/dumbgames/review_*.md`）
- **g4**：电脑领先后被“升兵贴脸”翻盘；Ham 一步“升象吃炮”（象二级攻击 2）电脑没想到。
- **g5**：电脑执楚输，Ham 原话“完全是虐杀”。关键一步电脑没算到“对方第二手先把兵升四级、神速营跳过来将军”。
- **g6**：电脑执汉，第 16 回合领先 20 分；Ham 的车杀进九宫，加上背水一战，第 23 回合起汉帅被将死网罩住。Ham 说“召回用得很烂”。
  原因有两条：一是规则让召回到落后一半大子才开；二是电脑留着召回不舍得用。
- Ham 的目标原话：**“AI 必须强到我悔棋也赢不了，至少很难赢”**。电脑这边数值部在做（调权重、多想、补盲区）。
- 设计上值得你们想：真人觉得什么地方“憋屈 / 不公平 / 看不懂”，哪些技能“想用但用不上”。

## 4. 数值部能测什么、要多久

- **能量的指标**：
  - 汉胜率、对局长度、各种结局（将死 / 困毙 / 决战 / 夺营）。
  - 每种技能、兵法、升级的使用率和击杀数。
  - 将死是什么子、贴不贴脸、守方丢几个士象。
  - 某种局面电脑怎么走（考题）。
  - 极端诊断：故意把某个技能调得很强 / 很弱，看电脑和平衡怎么反应。
- **多快**：
  - 改数字（价钱、冷却、血量、攻击、伤害、开启条件）：当天能测。一组 600 局在 GitHub 上大约 3 小时，几组可以一起排。
  - 新机制（新技能、新兵法）：要先写原型，1–2 天。
- **注意**：平衡要用最强的电脑测（电脑弱时偏 48%，强了偏 65%）。电脑不会“想用技能”，只会算值不值。某个技能电脑不用，可能是技能弱，也可能是电脑不懂。数值部能用“极端诊断”区分这两种情况。

## 5. 现在最值得顾问部先想的三件事

1. **偏汉了怎么办**：楚方要补什么？还是汉方削什么？方向和可选的几个具体改法。
2. **死技能**：齐射、践踏（四级相 / 象）、汉的四面楚歌几乎没人用，决战从来进不去。是改强、改条件，还是换掉？
3. **召回 / 背水的开启条件**：要落后到“车马炮剩 3 枚以下、比对方少”才能用，往往太晚了。这条要不要改，或者换一种“翻盘机制”？
