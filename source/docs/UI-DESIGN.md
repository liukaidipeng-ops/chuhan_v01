# 界面设计规范（E 棋盘）

美术写，2026-10-05。这是给动界面的人看的速查版；完整的设计阐述（初衷、五个方向的取舍、定稿过程、边界、升级方向，带实机截图）是 Ham 那边的文档《技能新象棋 · 界面设计阐述》，要看找 Ham 要链接。

**一句话**：屏幕是棋盘，入口是棋子，选一个功能就是落一枚子。界面不借书画、器物来形容这个游戏，只用象棋自己的东西：红黑两色、一张盘、圆的子。

## 七条规矩

1. **只用朱、米白、墨。** 想加第四种颜色时，先试试能不能用形状、大小或位置来区分。
2. **圆的是棋子，方的是棋格。** 没有圆角矩形。圆形只给「选一个、定下来」的动作。
3. **一页只有一个墨色实心的主操作。** 出现第二个，说明这一页要拆。
4. **每一页都要有棋盘。** 格线、河界或竖栏至少出现一样，主操作落在格线上。不能只是红底上摆几个控件。
5. **大字用粗宋，小字用黑体。** 粗宋只给标题、按钮、名字；超过一行的说明文字一律黑体。
6. **主操作固定在底部；打断对局越短的弹窗越小。**
7. **话说短。** 按钮写动作，确认只问一句，不替玩家解释他刚点的东西。

## 颜色和字

| 变量 | 值 | 用在哪 |
| --- | --- | --- |
| `--g` 朱 | `#a8281c` | 大厅和整页弹窗的底；对局里「轮到你」的外圈、兵法按钮 |
| `--c` 米白 | `#f0e7d2` | 所有的线；浅色棋子；朱底上的小字；对局里头像牌、棋谱的底 |
| `--k` 墨 | `#141311` | 大字标题；每页唯一的主操作；对局里的状态条、工具棋子、提示条 |
| `--ef` 大字 | 思源宋体 Black（`fonts/songhei-subset.woff2`，构建时嵌入） | 标题、按钮、棋子上的字、人名 |
| `--es` 小字 | 系统黑体 | 说明文字、选项格、长段正文 |

线一律 2 像素米白实线，相邻的框共用一条边。弹窗和对局里的牌用双线框（外一圈底色、里一条细线）。没有渐变、圆角、阴影造出来的层次。

## 两种屏幕

- **电脑**（宽 > 640）：横着的棋盘。主界面三条等高的带子——上半盘格子、河界、下半盘格子；二级页面每页至少留一条棋盘格，主操作的圆棋子落在格线交叉点上。
- **手机竖屏**（宽 ≤ 640）：竖河。左边一条竖栏竖写页名，右边是方格；主操作在固定的底栏里。手机不是电脑版缩小，入口是方格不是圆。

## 三种弹窗

| 种类 | class | 用在哪 |
| --- | --- | --- |
| 整页式（左竖栏 + 固定底栏；手机上全屏） | `.modal.e-m`，以及 `#mSet` | 内容长、要滚动的：设置、玩法说明、更新说明 |
| 小卡片（朱底、米白双线框，浮在棋盘上） | `.modal.e-c`，以及 `#bfTip`、`#pauseOv .pz` | 对局中临时打开、马上要关的：喊话、选择、观战入席、导出、规则速览、暂停 |
| 询问（米白底、墨线双框，一句话加两个按钮） | `#mAsk`；加 `e-stay` 时「留下」是大按钮 | 所有「是或否」 |

## 结构约定（改页面时照着来）

- 页面 / 弹窗的骨架：标题 `h3`（或 `.e-hd` 里的 `h3` + 返回）→ 内容包在 `.e-body` → 主操作包在 `.e-bar`。
- 新加的 class 都带 `e-` 前缀。
- 做新页面的顺序：先定这一页最大的字（放河界或竖栏）→ 再定唯一的主操作（墨色棋子或底栏里的墨色按钮）→ 其余内容填进方格 → 最后把整页缩小看一眼，还认不认得出是棋盘、内容有没有缩在一角。

## 没换的和已知的妥协

- 对局里的演出效果（將、倒数、晋升题签、军功飘字、色雾、字幕）仍是行书和金色，算演出不算界面。
- 电脑版河界写「楚河」「漢界」，手机竖栏写「技能新象棋」——Ham 说电脑版先不动。
- 终局卡片竖排的古文里有繁体字，粗宋字库里没有，那一段用系统宋体粗体。
- 终极兵法和主帅兵法的按钮都是朱底，靠多一圈线区分。
