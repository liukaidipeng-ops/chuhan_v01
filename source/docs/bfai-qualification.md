# 技能模式电脑：合格标准

先把电脑练到“合格”（真正懂血量、弹回、升级、技能、兵法这些机制），再拿它跑平衡模拟、调技能和数值。
电脑不懂机制时，模拟出来的胜率和技能使用率反映的是电脑的毛病，不是规则的强弱。

## 分工

| 谁 | 管什么 |
|---|---|
| 用户 | 提需求；亲自下棋，看到电脑走蠢棋就「导出本局」发过来；最后拍板“合格” |
| Claude（chat） | `src/` 下的游戏和电脑（`bfai.js`、`bingfa.js` 等）；部署到 `main` 只由它做 |
| Claude Code | `tools/` 下的考卷、模拟、闸门工具和这份文档；只往自己的分支推，合进 `dev` 由 chat 做 |

约定：
- 电脑用的引擎接口 `BF.ai` 只增不改；`BF.ai.version` 每加一个函数 +1，`bfai.js` 写明 `BFAI.apiVersion`。
- 电脑里所有随机都走 `Math.random`（工具会用固定种子替换它，结果才能复现）。
- 导出格式由 `tools/game_load.js` 负责（chat 维护），其他工具只调用它。

## 五道闸门

一条命令跑完：`node tools/bfai_gate.js [--prev git:上一版提交号] [--match-json 明细.json] [--quick]`
门槛写在 `tools/bfai_gate.json`；`null` 表示还没定、只量基准。上一版默认是 `bfai_gate.json` 里 `match.prev`（线上那一版，现在是 `git:25eb911`）。

**跑的顺序：自检 → 对打 → 考卷 → 漏着率。** 对打决定能不能上线，所以排在考卷前面（2026-10-03：cf47f5e 考卷满分，对打却以 35% 输给旧版——考卷全对 ≠ 更强）。

| # | 闸门 | 量什么 | 命令 | 局限 |
|---|---|---|---|---|
| 1 | 考题自检 | 考题本身摆得对：将帅不照面、将军状态对、标准答案合法且判对、错误示范判错 | `node tools/bfai_exam.js --lint` | 只查合法，不查“标准答案是不是真的好” |
| 1b | 深搜复核 | 每题用霸王档长时间深搜复核标准答案；不同意的交人裁决，裁决结果写进题里 | `node tools/bfai_exam.js --verify 8000` | 深搜和考生是同一个脑子 |
| 2 | 考卷 | 校尉、霸王两档的总分和每一类（血量 / 技能 / 军功 / 兵法 / 终极 / 决战 / 贴脸 / 破釜反击 / 实战）的分 | `node tools/bfai_exam.js --level mid` | 只是必要条件，会被“应试”；不能当唯一闸门。考满分的版本对打也可能更弱 |
| 3 | 漏着率 | 自对弈每一步用更深的搜索复核：失误、漏着、漏杀、送杀；第二裁判只看子力和血量，查“白丢子” | `node tools/bfai_quality.js --games 16` | 第一裁判和考生同一套估值；裁判要比考生深得多（搜索量 5 倍以上） |
| 4 | 不退步 | 新版对上一版，每个种子换边各一局，序贯检验打到能下结论就停，给出 Elo 差和 95% 区间 | `node tools/bfsim.js --match src/bfai.js,git:上一版 --json 明细.json` | 只比相对强弱。上一版要支持“按节点数收手”（25eb911 起）：更老的版本 `--nodes` 对它无效、按时间算，工具会提示 |
| 5 | 人工认可 | 用户亲自下几局，没有一眼能看出的蠢棋 | 记在 `bfai_gate.json` 的 `humanSignoff` | 最可靠，但慢 |

真正的闸门是 4 和 5。1～3 用来快速定位毛病、防止明显退步。

## 用户怎么参与（最有效的一环）

1. 和电脑下棋，看到电脑走了蠢棋，点「导出本局」（设置里、棋谱栏右上角）。
2. 把导出的文字连同一句话（比如“第 12 回合楚方那步车白送了”）发给 Claude。
3. Claude 用 `tools/game2exam.js` 把那一步收成一道“实战题”（存进 `tools/bfai_exam_games.json`，考卷自动读），再让 chat 照着修。

```
node tools/game2exam.js 对局.txt                    # 列出每一手
node tools/game2exam.js 对局.txt --turn 12楚        # 看那一手：棋盘、电脑走了什么、深搜觉得该走什么
node tools/game2exam.js 对局.txt --turn 12楚 --add --name "白送车" [--answer '<JSON>']
```

## 版本存档

不用复制文件：任何历史版本都能用 `git:提交号` 拉出来对打，例如
`node tools/bfsim.js --match src/bfai.js,git:bee5741`。
旧版电脑配当前的规则引擎；它用到引擎里已经没有的接口会当场报错，不会悄悄少功能。

## 电脑合格之后：平衡

- 用 `tools/bfsim.js` 跑当前规则，对照组用 `--preset baseline`（同一个电脑下普通象棋）。
- 每个兵法、每个技能都“关掉”跑一组（`--preset no-pofu`、`no-chongzhen`……），看汉方胜率变多少，量出它到底值多少。
- 注意：电脑不会用的技能，关掉之后胜率也不变——所以这一步要等电脑合格之后做。
- 电脑对打时双方不对称（先手、兵法都不同），新旧电脑比较一律换边各打一半。
