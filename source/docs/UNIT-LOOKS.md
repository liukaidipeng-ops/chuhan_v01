# 兵种外观表

技能新象棋（项目暂用名，原名「楚汉三维象棋」）里每个兵种、每一级在棋盘上长什么样：人数、装束、配色、武器。做新兵种、改老兵种都照这张表来。

- 归 TD 管。全部照 `dev` 分支的代码核过（2026-10-05），出处写的是文件和函数名。**表和代码对不上，以代码为准，并告诉 TD 改表。**
- 颜色写的是代码里的十六进制值，后面括号里是大致的颜色名。
- 文件都在 `source/src/`：`squads.js`（小队：几个人、怎么排、多大）、`models.js`（模型：长什么样、什么颜色）、`bingfa.js`（等级上限、称号）、`board.js`（棋子本身）。

---

## 1. 先看这几条总规律

1. **两种编制。**普通模式和揭棋没有等级，每个兵种按“原编制”出场（比如兵卒是 12 人方阵）。技能模式有等级，**出场人数跟着等级走**，一级往往只有 1 个。
2. **一到三级：逐级加人，模型不变。**1 → 2 → 3（个人、匹马、辆车、头象、门炮）。人少的时候单个画大一点，人多了缩小，占的地方差不多。
3. **四级：不再加人，换金装。**兵卒、士、汉相、楚象都是这样。
4. **车是唯一的例外**：四级还是三辆战车，战车不换金，但前面多一名骑马的金甲双锤大将。
5. **汉相（虎骑，10-05 起线上）一到四级都是一虎一人**：三、四级行进和攻击时两侧才各出一名弩手。旧的弩队（`?tiger=0`）是一、二级两名弩手，三、四级四名。
6. 马、炮最高三级，没有金装。帅将没有等级。
7. 二级起队伍旁边多一面小旗：二级「銳」，三、四级「精」。
8. 金装的金是这几个值：甲 `0xd6a43e`、饰件 `0xf3d27a` / `0xf7dc8c`。顶点色落在金色范围里的面会被自动画成金属（`models.js` 开头的 `vcMat`），所以金饰直接给金色就行。

|---|---|---|---|---|---|
| 兵卒 | 12 人方阵 | 1 人 | 2 人 | 3 人 | 3 人，金甲、斩马刀、大盾 |
| 士 | 2 人 | 1 人 | 2 人 | 3 人 | 3 人，金甲、金盾 |
| 汉相（虎骑，线上） | 1 虎 1 人 | 1 虎 | 1 虎 | 1 虎（行进、攻击时 + 2 弩手） | 金甲虎骑（行进、攻击时 + 2 金甲弩手） |

| 楚象 | 1 头 | 1 头 | 2 头 | 3 头 | 3 头，全换金 |

## 2. 通用的东西

### 2.1 等级从哪儿来

- 入口是 `squads.js` 的 `make(t, side, anchor, yaw, role, lv, n)`。`n = 0` 是原编制；技能模式传 `n = 等级`。
- 等级上限在 `bingfa.js`：`maxLevel: { r: 4, p: 4, a: 4, e: 4 }, defaultMaxLevel: 3`，帅将固定 1。所以**车、兵卒、士、相 / 象能到四级，马、炮到三级**。
- 兵种字母：`p` 兵卒、`a` 士、`e` 相 / 象、`r` 车、`n` 马、`c` 炮、`k` 帅将。阵营：`r` 汉（红）、`b` 楚（黑）。

### 2.2 升级带来的通用变化（`Squad.rank(lv)`）

| | 二级 | 三级、四级 |
|---|---|---|
| 小旗 | 「銳」字旗，缩放 0.075 | 「精」字旗，缩放 0.1 |
| 给步兵整体罩一层色 | `0xf0d6a0`（浅金），力度 0.22 | `0xffcf6a`（金黄），力度 0.4 |

- 罩色只作用在“成队的步兵”身上：兵卒、士、汉相的弩手。车、马、象、炮、虎骑、帅将不罩色，只多一面旗。
- `rank` 没有四级的分支：四级的旗和罩色与三级相同，金装是换模型换出来的。
- 「模型模式」（设置里「棋子显示 → 兵种模型」，队伍一直站在棋盘上）不插这面旗，改成领头的背一面写着棋子字的背旗，脚下一个光圈（汉 `0xc8281a` 红、楚 `0x141210` 黑）。

### 2.3 人少画大、人多缩小

- 成队的步兵用 `bigFor`：1 人 ×1.5、2 人 ×1.35、3 人 ×1.22；四级再 ×1.08。
- 车、象、炮用 `addEchoes` 复制：2 个 ×0.8、3 个 ×0.68，一字排开、两侧略靠后。
- 基准缩放：步兵 `SC = 0.2`、骑兵 `HS = 0.22`、战车 `CH = 0.25`、炮 `CN = 0.26`、象 `EL = 0.22`、主帅 `HERO = 0.21`、虎骑 `0.26`（精修版 0.27）。

### 2.4 阵营配色（`models.js` 的 `SIDE`）

| 用在哪 | 汉 | 楚 |
|---|---|---|
| 衣（`cloth`） | `0xa8321f` 朱红 | `0x2a292c` 玄黑 |
| 衣的浅色（`cloth2`） | `0xc4553a` 浅朱 | `0x48464a` 深灰 |
| 甲（`armor`） | `0x4d4541` 铁灰褐 | `0x2f2e31` 乌铁 |
| 饰边（`trim`） | `0xc9a045` 金 | `0x9c8a62` 暗铜金 |
| 旗（`flag`） | `0xb0301f` 红 | `0x1f1e20` 黑 |
| 缨（`tassel`） | `0xc0412c` 朱 | `0x7a2418` 暗红 |
| 马（`horse`） | `0x6b4a34` 栗色 | `0x2c2a2a` 黑 |
| 马甲（`barding`） | `0x5e2a20` 暗红 | `0x262528` 黑 |

通用色（`C`）：肤 `0xd8bf98`、裤 `0x2d2a27`、木 `0x6e4a2c`、铁 `0xb8b4aa`、深色 `0x1d1c1b`、铜 `0x7a6238`、发 `0x151413`、白 `0xece4d2`、牙白 `0xe8dcc0`、金 `0xb08a3a`。

### 2.5 通用步兵的身子（`Models.Troop`，所有步兵共用）

- 头：甲色的盔，顶上一根尖，两片护颊，盔缨是缨色。
- 身：甲色的裙甲，衣色的上身，甲色的胸甲，深色腰带，胸前一块饰边色的护心牌，甲色的肩。
- 四肢：深色裤、甲色胫甲、深色靴；衣色袖子、甲色护臂。
- 武器上的缨：汉 `0xb0301f`、楚 `0x5a1a14`。
- 金装步兵（`zhanma` 斩马刀兵、`guardG` 金甲禁卫、`xbowG` 金甲弩手）：甲换成 `0xd6a43e`，护心牌换成 `0xf3d27a`；**衣、缨仍是本方颜色**。

### 3.4 汉相 · 虎骑（`TigerRider`，模型在 `tiger.js`，归美术；现在是 M2 版）

10-05 Ham 点头上线，现在是默认形象（`models.js` 的 `TIGER_ON = true`）；网址带 `?tiger=0` 退回弩队。

| | 虎 + 骑手 | 随护 | 另外 |
|---|---|---|---|
| 普通模式 | 1 | 无 | |
| 一级 | 1 | 无 | |
| 二级 | 1 | 无 | 「銳」旗 |
| 三级 | 1 | 平时没有；行进、攻击时两侧各出 1 名弩手 | 「精」旗 |

- **白虎**：白底黑纹，额上一个「王」字，琥珀色眼，耳背和尾尖黑。压低身子潜行的站姿：后腿三段（大腿、小腿、跗骨），四肢往外撑开，脚掌大，头压得比肩低。
- **鞍具**：朱锦褥、前后黑漆鞍桥，垂缨；金项圈。
- **文臣**：朱红宽袍、黑缘、金带、白内领、长须、进贤冠；右手持汉节（三重红旄），左手虎符。
- **四级金装**（Ham 定的：文臣衣冠不变、手持金色权杖、老虎身披金甲）：
  - 虎身披鱼鳞式金札甲——颈甲、肩甲、当胸、搭后，有厚度；额带、红缨、当卢、四只金镯。
  - 鞍换成宝座式，后鞍桥升成一面尖拱靠背。
  - 节杖整根鎏金，红旄保留。
  - 文臣的衣冠**不变**；白虎的毛色不变。
- **随护弩手平时不在场**（Ham 10-05 定的，嫌杂乱）：棋盘上站着的虎骑，一到四级都是一虎一人。只在行进和攻击时出列（原地一小团墨气现身），走到位、打完就退下；挨打的一方不出弩手。
- 普通攻击：一、二级是虎扑（伏低咆哮 → 窜出 → 腾身扑下）。三、四级是组合——两侧弩手先放一轮箭，箭到，虎才窜出去扑咬；弩手留在原地不跟。「齐射」是弩手放两轮箭，虎伏着不动。
- **节杖不动**（Ham 10-05 定的）：咆哮、扑击时节杖保持平时的朝向，象征权威；文臣不近战，只有虎在打。美术 M2 的动作里节杖会前指，TD 先在 `TigerRider` 里每帧扶正，等美术改了动作再拿掉（`main-to-model.md` H5）。
- 倒地时虎留在原格，文臣和节杖倒向旁边没有子的一侧。
- 台词、称号、虎啸跟着模型一起上线：移动「白虎开道」「谋定而后动」，吃子「犯汉者，虎噬之！」「放虎！」；称号见第 4 节。

## 6. 做新兵种、改老兵种时要交代清楚的

照上面的规律，一个兵种要有这几样（哪样不适用就在交付单里写明）：

1. **原编制**长什么样（普通模式、揭棋用）。
2. 技能模式**一、二、三级各出几个**，怎么排，单个多大。默认照 1 → 2 → 3；想例外（像汉相、车那样）先问 Ham。
3. **四级金装**：哪些部分换金、哪些不换。默认不加人；能升四级的只有车、兵卒、士、相 / 象。
4. 汉、楚两边各自的配色，用 2.4 的色表，不另起颜色；确实要新颜色，在交付单里列出来。
5. 低画质档的样子，面数预算见 `MODEL-WORKFLOW.md` 第 5 节。
6. 从正常对局视角看，和别的兵种的剪影能一眼分清。
